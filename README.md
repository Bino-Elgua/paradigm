## Quick Start

```bash
# Clone and setup
git clone https://github.com/Bino-Elgua/paradigm.git
cd paradigm
npm install

# Configure (optional - for full LLM support)
cp .env.example .env
# Add ANTHROPIC_API_KEY=sk-ant-... if desired

# Run server
npm start
# Server: http://localhost:3000

# Test consciousness
curl -X POST http://localhost:3000/api/v1/consciousness

# Get autonomy report
curl http://localhost:3000/api/v1/autonomy/report
```
